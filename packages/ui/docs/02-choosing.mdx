## Tooltip·Hint·Tour·Peek

UI의 뜻 한 줄은 Tooltip, 새 기능 알림은 Hint, 요청한 단계 안내는 Tour, 레코드 미리보기는 Peek를 고릅니다.

## DescriptionList·DataTable·Peek

열 머리글 없는 키-값(주문 정보·배송지·결제 내역·합계)은 DescriptionList, 같은 열을 여러 행으로 비교하면 DataTable, 표의 행을 열지 않고 훑어보는 요약은 Peek를 고릅니다.

## DatePicker와 네이티브 날짜 입력

업무 날짜·기간 필터는 DatePicker를 우선하고, 네이티브 날짜 입력이 꼭 필요한 경우에만 `<input type="date">`의 문자열 value를 사용합니다.

<div className="intent-grid"><Intent name="DatePicker" /><Intent name="Input" /></div>

네이티브 날짜 입력은 실측에서 text 입력과 다른 고정적인 기본 폭을 보였고, `valueAsDate`는 UTC 자정이며 검증 문구는 영어였습니다. <DesignLink section="17.1">DESIGN.md §17.1 실측과 날짜 입력 근거</DesignLink>를 확인하세요. 위 Input 블록은 네이티브 타입을 전달하는 래퍼의 규칙입니다.

## 금액·수량은 text 입력으로

`type="number"`는 휠·화살표로 값이 달라지고 쉼표·지수 표기 해석이 업무 입력과 어긋날 수 있습니다. <DesignLink section="17.1">§17.1의 실측 표</DesignLink>를 읽고 다음처럼 시작하세요. 검증 오류는 앱에서 한국어로 제공합니다.

```tsx
<Input type="text" inputMode="numeric" numeric aria-label="주문 금액" />
```
