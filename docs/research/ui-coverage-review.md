# UI 요소 준비도 검토 (2026-11-21)

질문: 네 제품(이커머스 판매관리 · 물류관리 · 마케팅관리 · CMS)을 바이브코딩으로 만들 때 필요한 UI 요소가
디자인 시스템에 준비돼 있는가.

근거: 현재 매니페스트(루트 46 · 부품 포함 102), 도그푸딩 1–4 에서 **사람·AI 가 직접 만들어야 했던 것**,
네 제품의 대표 화면(목록 · 상세 · 등록 · 대시보드).

## 지금 있는 것 (루트 46)

| 분류 | 컴포넌트 |
|---|---|
| 폼 (12) | Input · Textarea · Select · Combobox(단일·다중) · MultiSelect · DatePicker(날짜·기간) · Checkbox · RadioGroup · Switch · Label · Field · FormFlow |
| 표 (1) | DataTable — 정렬 · 선택(빠진 행 자동 해제) · 가상화 · 무한 스크롤 · 열 고정 · CSV |
| 차트 (4) | ChartFrame · TrendBand · BulletRow · CompositionArea |
| 오버레이 (3) | Dialog · AlertDialog · Peek(레코드 요약) |
| 탐색 (2) | Tabs · Breadcrumb |
| 액션·상태 (4) | Button · DropdownMenu · StatusChip · Toaster |
| 로딩·상태 (10) | Skeleton 류 6 · ProgressTrack · TaskProgress · EmptyState · ErrorState |
| 미디어 (4) | Avatar · Thumbnail · Carousel · MediaViewer |
| 펼침·안내 (5) | Collapsible · ClampText · Tooltip · Hint · Tour |
| 배치 (1) | Card |

목록·상세·등록 화면의 **부품 수준**은 대부분 덮는다. 도그푸딩 4 에서 AI 가 한 번의 요청으로 목록·작성 화면을
지침대로 조립한 것이 근거다.

## 비어 있는 것 — 우선순위

### P1 · 모든 제품에 필요하고, 없으면 매번 즉흥으로 만든다

| 요소 | 근거 | 비고 |
|---|---|---|
| **앱 셸** — 사이드 내비게이션 · 상단 바 · 페이지 머리(제목·설명·주요 액션) | 도그푸딩 4 AI 가 셸·사이드바를 직접 작성. 1–3 앱도 제각각 | 네 제품의 "같은 회사 제품" 인상을 가장 크게 좌우한다 |
| **검색 입력** — Input 앞쪽 아이콘 | 도그푸딩 4 V1 (아이콘이 가려짐) | Input 의 앞쪽 아이콘 자리 또는 검색 전용 입력 |
| **페이지네이션** | DataTable 은 가상화·무한 스크롤만 있다. B2B 목록은 페이지 이동·페이지 크기·전체 건수가 표준(서버 페이징) | 주문·출고·게시글 목록 전부 |
| **파일 업로드** — 드롭존 · 이미지 미리보기 · 진행률 | 도그푸딩 4 AI 가 점선 상자를 직접 그림 | CMS 대표 이미지, 상품 이미지, 엑셀 일괄 등록 |
| **옆 패널 (Sheet/Drawer)** | 목록에서 화면 이동 없이 상세·편집·필터. Peek 는 요약 전용(수정 금지)이라 대신할 수 없다 | 물류 출고 처리, 주문 상세 빠른 편집 |

### P2 · 여러 제품에 반복되지만 우회 가능

| 요소 | 근거 |
|---|---|
| 날짜+시간 선택 | CMS 예약 발행, 마케팅 캠페인 시작 시각. 도그푸딩 4 에서 날짜만 받았다 |
| KPI 지표 타일 (값 + 증감) | 대시보드 상단. 차트는 있으나 단일 수치 타일이 없다 |
| 세그먼트 컨트롤 / 토글 그룹 | 보기 전환(표·카드), 기간 단위(일·주·월) |
| 단계 표시 (Stepper) | 상품 등록·캠페인 생성 같은 여러 단계 폼 |

### P3 · 필요할 때

리치 텍스트 편집기(외부 라이브러리를 감싸는 방식) · 계층 카테고리 트리 · 칸반 보드(물류 상태) · 알림 센터.

## 이미 있는 것의 결함 (도그푸딩 4)

- CardBody 만 쓰면 위 여백이 없다 (V2)
- Select 계열 트리거 모양 불일치 — Combobox 다중의 글자 시작·꺾쇠 색 (V3)
- `.sr-only` · `.tabular` 같은 공개 유틸리티가 있는지 문서에 없다

## 권장 진행

1. 결함 3건(V1 은 P1 검색 입력과 같이) — 작다
2. P1 을 하나씩. **앱 셸 → 페이지네이션 → 검색 입력 → 옆 패널 → 파일 업로드** 순서
   (앱 셸이 다른 화면의 틀이라 먼저). 각각 도그푸딩 4 와 같은 방식(바이브코딩 요청 한 번)으로 검증
3. P2 는 P1 뒤에 제품 화면을 만들며 필요가 확인되는 순서로
