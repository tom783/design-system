# R40b · 달력 보정 — 이번 달·이웃 달 날짜 색, 모드별 빠른 선택

R40 하네스 12/12 후 열린 달력을 라이트·다크로 봤다. 아래 두 가지는 **R40 이전부터 있던 결함**이다(날짜만 있는 단일 모드에서도 같다).
시각 모드에서 더 드러난다. 버전은 올리지 마라.

## 1. 이번 달과 이웃 달 날짜가 같은 색

실측(라이트, `components-datepicker--단일날짜`): 11월 1·11일과 이웃 달 12월 5일(`data-outside="true"`)이 모두 `rgb(83, 76, 75)` = `--text-secondary`.
어느 칸이 이번 달인지 색으로도 굵기로도 구분되지 않는다.

- 이번 달 날짜 `--text-primary`, 이웃 달 날짜는 한 단계 흐리게(`--text-tertiary` — 대비 4.5:1 이상인지 실측해 라이트·다크 표에 적어라).
  선택·오늘·범위 중간 칸의 기존 표시는 그대로. 이웃 달 날짜를 고를 수 있는지(지금 동작)는 바꾸지 마라

## 2. 모드에 맞지 않는 빠른 선택

지금은 모든 모드가 "오늘 · 최근 7일 · 이번 달 · 지난 달" 을 보인다. 단일 모드에서 "이번 달" 은 그 달의 끝날을 고른다
(`quickRange(period).to`) — 하나의 날짜를 고르는 화면에 기간 단추가 있다. 예약 일시(time)에서는 "지난 달" 이 맞지 않는다.

- range: 지금 그대로 4개
- single(날짜): "오늘 · 어제" — 조회 필터에서 흔하다
- single + time: "오늘 · 내일" — 예약은 앞날이다. 시각은 지금처럼 유지
- DESIGN 날짜 절·MCP DatePicker 규칙 문장이 빠른 선택을 설명하면 함께 맞춘다(새 규칙은 늘리지 마라 — 카탈로그 80,286)

## 하네스 (실행은 내가 한다)

- 날짜 관련 하네스에 "이번 달 날짜 색 = `--text-primary`, 이웃 달 = 흐린 토큰, 둘이 다르다(라이트·다크)" 와 "모드별 빠른 선택 목록" 단정
- 기존 단정이 옛 빠른 선택 목록(단일에서 4개)을 전제하면 **그 단정만** 고치고 목록을 보고하라
