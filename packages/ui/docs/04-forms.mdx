# 폼 만들기

값과 검증 내용은 앱에서 관리하고, Field가 레이블·설명·오류·접근성 배선을 맡도록 조립합니다.

<Intent name="Field" />

```tsx
<Field label="수취인" description="주문서에 인쇄됩니다" error={error} required>
  <Input value={recipient} onChange={event => setRecipient(event.target.value)} />
</Field>
```

## Enter 이동

FormFlow는 Enter를 Tab 순서의 다음 칸 이동으로 연결하며, 컨트롤별 예외는 <DesignLink section="11.5">DESIGN.md §11.5의 Enter 이동 계약 표</DesignLink>를 따릅니다.

<Intent name="FormFlow" />

첫 칸에 값을 입력하고 Enter를 눌러 보세요. 마지막 일반 입력에서는 제출됩니다.
