# 차트

시간에 따른 추이와 편차는 TrendBand, 실적과 목표의 비교는 BulletRow, 구성 비율의 변화는 CompositionArea를 씁니다. 세 차트는 SVG로 그려 의미 토큰과 테마를 상속하며 컨테이너 폭이 바뀌면 좌표를 다시 계산합니다. 화면의 질문에 맞춰 하나를 고르고, 차트가 전달하는 결론을 한 문장으로 작성하세요.

## 요약 문장은 어디에 보이나요?

`summary`는 화면에 표시하는 본문이 아니라 차트의 `<svg role="img">`에 붙는 `aria-label`입니다. 스크린리더가 개별 좌표를 나열하는 대신 차트의 결론을 읽도록 하는 계약입니다. 근거는 <DesignLink section="7.5">차트 설계 원칙</DesignLink>에 있습니다. 로딩·빈 결과·오류에서는 정상 데이터의 결론을 읽히지 않습니다.

화면에도 결론을 보여주려면 앱이 차트 옆이나 아래에 `<p>` 같은 본문을 추가하고, 정상 데이터가 있을 때만 같은 결론 문장을 표시하세요. ChartFrame은 `title`을 `figcaption`으로 표시하고 범례·플롯 높이·로딩·빈 결과·오류를 제공합니다. `summary`를 본문으로 출력하거나 결론을 넣는 별도 슬롯을 제공하지 않습니다. ChartFrame으로 직접 SVG를 조립하는 경우에는 자식 SVG의 `role="img"`와 `aria-label`도 앱이 연결합니다.

## 계열 색

계열 색으로 쓸 수 있는 CSS 변수는 다음 다섯 개입니다. `series[].color`에는 `var(--status-neutral-fg)`처럼 전달하세요. 목록 밖 이름은 그려지지 않고 검게 보이며 범례 색 칸이 빌 수 있습니다.

| 계열 | CSS 변수 |
|---|---|
| 중립·대기 | `--status-neutral-fg` |
| 안내 | `--status-info-fg` |
| 경고 | `--status-warning-fg` |
| 성공 | `--status-success-fg` |
| 오류 | `--status-danger-fg` |
