## 0. 전제

도그푸딩 4 AI 의 셸이 필요로 한 것(= 소비자가 기대하는 것): 브랜드 · 아이콘+라벨 메뉴 · 현재 위치(`aria-current="page"`) ·
준비 중(비활성) 메뉴 · 본문 영역. 페이지마다 제목·설명·주요 버튼(예: "새 글 작성")을 같은 자리에 두었다.

## 1. 결정 (B2B 관리 화면의 표준 — Storybook·Figma 에서 사용자가 보고 피드백한다)

- **왼쪽 사이드 메뉴 + 본문.** 상단 바는 선택 슬롯(전역 검색·사용자 메뉴 자리)
- 사이드 메뉴 폭 240px, **접으면 아이콘만 남는 레일 64px**. 접힌 상태에서 항목은 Tooltip 으로 라벨을 보인다
- 1024px 미만에서는 자동으로 레일. 화면 밖에서 열리는 서랍은 옆 패널(R36) 다음 라운드로 미룬다
- 사이드 메뉴 바탕 `bg-surface`, 본문 바탕 `bg-canvas` — 경계는 1px `border-subtle`
- 현재 위치: `bg-selected` + 굵기 600 + `aria-current="page"`. 색만으로 표시하지 않는다(굵기·배경)
- 본문 안쪽 여백 24px(좁은 화면 16px). 본문 최대 폭은 기본 없음(표는 넓게), 선택 prop 으로 제한 가능
- 키보드: 셸 맨 앞에 **"본문으로 건너뛰기"** 링크(포커스 받을 때만 보임) → 본문 랜드마크로
- 랜드마크: `nav`(aria-label "주 메뉴"), `main`

## 2. 컴포넌트 (이름은 제안 — 바꾸면 이유를 보고)

- `AppShell` — `sidebar`·`header?`·`children`. 건너뛰기 링크·랜드마크·반응형 레일 전환을 소유
- `SideNav` — 브랜드 슬롯, 그룹(제목), 항목(아이콘·라벨·배지/개수·비활성·현재 위치). 항목은 링크여야 하므로 `asChild`
  (Next `Link` 등) 지원. 접힘은 제어·비제어 둘 다(`collapsed`·`onCollapsedChange`·`defaultCollapsed`), 접기 버튼 내장.
  접힘 상태 저장은 앱 몫(규칙에 적어라)
- `PageHeader` — 경로(Breadcrumb 슬롯)·제목(h1)·설명·상태(StatusChip 등 슬롯)·주요 액션(오른쪽). 좁으면 액션이 아래로
- 비활성("준비 중") 항목은 포커스·클릭 불가, `aria-disabled`, 라벨 옆 표시

## 4. 검증

`npm_config_offline=true pnpm verify`, `node docs/qa/mcp-client-verify.mjs .qa-shots/mcp-client-verify`.

하네스 (작성만):
- 폭: 펼침 240 · 접힘 64 · 1024 미만 자동 레일. 접힘에서 항목 호버·포커스 시 Tooltip 라벨
- 현재 위치 항목: `aria-current="page"`, 굵기 600, 배경 `bg-selected` — 라이트·다크
- 건너뛰기 링크: 첫 Tab 에 보이고, Enter 로 `main` 에 포커스
- 비활성 항목: Tab 순서에 없음, 클릭해도 이동 없음
- PageHeader: h1 하나, 좁은 폭에서 액션이 제목 아래로 내려가며 가로 넘침 없음
- 사이드 메뉴 스크롤: 항목이 많으면 메뉴만 스크롤, 본문 스크롤과 독립
- 콘솔 오류 0
