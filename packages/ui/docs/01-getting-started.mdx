# 시작하기

처음 붙이는 화면은 설치 → 공통 CSS → 컴포넌트 순서로 시작합니다. 이 문서는 현재 저장소의 API를 기준으로 합니다.

```sh
npm install @s2life/ui pretendard
```

React와 React DOM 19(19.0 이상)는 peer 의존성이며 React 18은 지원하지 않습니다. 앱에 없다면 `npm install @s2life/ui pretendard react react-dom`으로 함께 설치합니다.
앱에 `@s2life/tokens`를 따로 설치하지 않습니다 — ui가 같은 버전을 고정해 가져오며, 따로 설치하면 버전이 어긋날 수 있습니다.

## 공통 CSS를 넣는 곳

일반 React 앱은 앱 진입점(예: Vite의 `src/main.tsx`)에서 아래 두 줄을 한 번 불러옵니다.

```tsx
import 'pretendard/dist/web/variable/pretendardvariable-dynamic-subset.css';
import '@s2life/ui/styles.css';
```

글꼴 파일은 용량과 호스팅 방식을 앱이 정하도록 ui 패키지에 넣지 않습니다. Pretendard CSS의 동적 서브셋은 번들러가 앱에서 자체 호스팅하며 외부 CDN이 필요 없습니다. 불러오지 않으면 시스템 글꼴로 그려져 숫자 폭·줄바꿈이 디자인과 달라집니다. Pretendard는 Google Fonts에 없으므로 `next/font/google` 대신 위 CSS import를 사용합니다.

`styles.css`는 토큰·유틸리티·컴포넌트 스타일이 들어 있는 사전 컴파일 CSS입니다. **Tailwind 설치나 설정은 필요 없습니다.** 토큰 CSS를 따로 불러오지 않습니다.

`styles.css`는 앱 전체에 적용되는 기본 초기화(Tailwind preflight)와 유틸리티를 포함합니다. **앱 전체를 이 디자인 시스템으로 만드는 것을 전제로 합니다.** 기존 앱의 일부 화면에만 넣는 부품 전용 CSS(preflight 없는 파일)는 제공하지 않습니다 — `styles.css`든 `tailwind.css`든 불러오면 앱 전체의 기본 스타일이 함께 바뀝니다. 우리 고유 클래스는 `ds-`로 시작합니다. 앱 CSS 클래스는 `ds-`로 시작하지 않으며, `.flex`·`.hidden` 같은 유틸리티 이름을 다시 정의하지 않습니다.

제공하는 유틸리티: `.sr-only`는 스크린리더용 문구를 화면에서 숨기고, `.tabular`는 숫자 열을 고정폭으로 정렬한다. `styles.css`·`tailwind.css` 두 경로에서 제공하며 `.truncate`는 공개 계약에 포함하지 않는다.

토큰 파일을 직접 써야 한다면 `@s2life/ui/tokens.css`, Tailwind 이름 매핑은 `@s2life/ui/theme.css`, 기계 판독용 값은 `@s2life/ui/tokens.json`으로 가져옵니다. `styles.css`와 `tokens.css`를 중복으로 불러오지 않습니다.

Next.js App Router는 루트 `app/layout.tsx`에 넣습니다.

```tsx
import type { ReactNode } from 'react';
import 'pretendard/dist/web/variable/pretendardvariable-dynamic-subset.css';
import '@s2life/ui/styles.css';

export default function RootLayout({ children }: { children: ReactNode }) {
  return <html lang="ko"><body>{children}</body></html>;
}
```

Next.js App Router에서 동작합니다. 부품 파일마다 `"use client"`가 붙어 있어 서버 컴포넌트 페이지에서도 import할 수 있고, 페이지가 쓴 부품만 클라이언트 번들에 들어갑니다. `@s2life/ui/icons`의 아이콘은 서버에서 그려집니다. 이벤트 핸들러나 React 상태를 직접 정의하는 앱 컴포넌트에는 앱의 `"use client"`가 필요합니다. `cn()`·`buttonVariants()` 같은 함수는 클라이언트 컴포넌트에서 호출합니다.

Next 16 기본 빌드(Turbopack)는 설정이 필요 없습니다. webpack으로 빌드하면(`next build --webpack`) `next.config`에 `experimental: { optimizePackageImports: ['@s2life/ui'] }`를 넣어야 쓰지 않는 부품이 빠집니다 — 빠뜨리면 모든 부품이 클라이언트 번들에 실립니다.

```tsx
// app/orders/page.tsx — 서버 컴포넌트 페이지
import { Button } from '@s2life/ui';

export default function OrdersPage() {
  return <Button asChild><a href="/orders/new">주문 등록</a></Button>;
}
```

## 다크 모드: 세 가지 상태

| 사용자 선택 | 루트 html에서 할 일 |
| --- | --- |
| OS 추종 | `data-theme` 속성을 제거합니다. 기본 상태입니다. |
| 라이트 | `data-theme="light"`를 지정합니다. |
| 다크 | `data-theme="dark"`를 지정합니다. |

앱의 테마 설정 이벤트에서 속성을 바꿉니다. OS 추종으로 돌아갈 때는 `data-theme="system"`을 쓰지 않습니다.

```ts
function applyTheme(theme: 'system' | 'light' | 'dark') {
  if (theme === 'system') document.documentElement.removeAttribute('data-theme');
  else document.documentElement.dataset.theme = theme;
}
```

## 링크를 버튼처럼 표시하기

`asChild`에 링크 하나를 넣습니다. Next `Link`도 같은 자리에 넣을 수 있습니다. 스타일 클래스만 필요하면 `buttonVariants()`를 씁니다.

```tsx
import Link from 'next/link';
import { Button, buttonVariants } from '@s2life/ui';

export function OrderLinks() {
  return <>
    <Button asChild variant="primary"><Link href="/orders/new">주문 등록</Link></Button>
    <a href="/orders" className={buttonVariants({ variant: 'secondary' })}>주문 목록</a>
  </>;
}
```
