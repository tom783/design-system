# R43b · 단계 연결선 — 떠 있는 짧은 줄표를 이어진 선으로

R43 하네스 9/9 후 스크린샷(1000px, 4단계)에서 찾았다. 버전은 올리지 마라.

## 실측

- 단계 칸은 같은 폭(1000px 에서 약 230px)인데 라벨은 70–90px. 연결선은 **16px 고정**이라 칸 안에 140px 안팎의 빈 공간이 남고,
  선은 다음 단계 표식 앞에 떠 있는 짧은 줄표처럼 보인다. 단계가 이어진 흐름으로 읽히지 않는다

## 고칠 것

- 가로 배치에서 연결선이 **라벨(또는 설명) 끝 + 간격 8px 부터 다음 단계 표식 앞 8px 까지 채운다**(최소 16px).
  세로 위치는 표식(원) 가운데. 완료된 구간의 선은 진하게(예: `--border-strong` 또는 완료 색), 남은 구간은 `--border-subtle` —
  색만으로 상태를 말하지 않으므로 선 색은 보조 신호일 뿐이다(대비 요건 없음, 근거를 한 줄로)
- 긴 라벨(말줄임)에서도 선이 최소 16px 남는다. 좁은 폭 요약(640 미만)은 지금 그대로

## 하네스 (`steps-render-verify.mjs` — 실행은 내가 한다)

- 1000px·4단계: 각 연결선 왼쪽 = 라벨 오른쪽 + 8(±1), 오른쪽 = 다음 표식 왼쪽 − 8(±1), 세로 가운데 = 표식 가운데(±1)
- 긴 라벨 스토리: 선 폭 ≥ 16
- 기존 단정 유지
