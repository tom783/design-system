# 도그푸딩 4 · 바이브코딩 — CMS 게시글 관리

이 디자인 시스템의 목적은 "패키지를 받아 **바이브코딩으로** 빠르게 UI 를 만든다"이다. 1–3 회차는 내가 타입 선언과
문서를 읽고 손으로 짰다. 이번에는 실제 사용 장면을 재현했다 — **저장소를 모르는 별도 AI 세션에 짧은 한국어 요청
한 번**만 주고, 결과를 쟀다. CMS 는 예시 주제일 뿐이고 만든 화면은 측정 후 버린다.

## 조건

- 빈 Next.js 16 앱(create-next-app 수준) · README 대로 `@s2life/ui` + `pretendard` 설치 · `@s2life/mcp` 연결
  (main `791772f` 의 팩, 0.3.1 후보). 레이아웃에 디자인 시스템 CSS 를 **미리 넣지 않았다**
- 별도 Claude Code 세션(`claude -p`), MCP 는 s2life 하나만(`--strict-mcp-config`)
- 요청 원문:
  > CMS 게시글 관리 화면을 만들어줘.
  > - 게시글 목록: 제목 검색, 카테고리·상태 필터, 표(제목·작성자·카테고리·상태·발행일), 행마다 수정·삭제
  > - 게시글 작성: 제목, 카테고리, 태그(여러 개), 공개 범위, 예약 발행일, 본문, 대표 이미지 미리보기
  > 디자인은 설치해 둔 @s2life/ui 디자인 시스템으로 맞춰줘. 데이터는 가짜로 넣어도 돼.

## 지침을 따른 것 (MCP·문서가 통했다)

| 지침 | 결과 |
|---|---|
| 설치·CSS (R27·R30) | `import 'pretendard/…dynamic-subset.css'` + `import '@s2life/ui/styles.css'` **문서와 같은 두 줄** |
| 라디오 묶음은 Field 로 (R31) | `<Field label="공개 범위"><RadioGroup>` → 접근 이름 "공개 범위" |
| 행 액션 (R31) | ghost 버튼 + 행을 밝히는 `aria-label`("○○ 수정") + 열 제목 화면에서 숨김("관리") |
| 링크 버튼 (도그푸딩 1 G3) | `<Button asChild><Link>` |
| 다중 태그 | `which_component` → `Combobox multiple` |
| 그 밖 | StatusChip 톤 · AlertDialog 삭제 확인 · DatePicker · Thumbnail · Select · Textarea · 앱 CSS 는 의미 토큰만 사용 |

## 고쳐야 했던 것 — 3건, 모두 디자인 시스템 쪽 원인

| | 증상 | 원인 |
|---|---|---|
| V1 | 목록 검색 입력의 돋보기 아이콘이 안 보인다 (왼쪽 여백 36px 만 남음) | **Input 에 앞쪽 아이콘 자리가 없다.** AI 가 아이콘을 절대 위치로 겹쳤고 Input 바탕이 덮었다 |
| V2 | 작성 화면 왼쪽 카드의 "제목" 이 카드 테두리에 붙는다 (간격 1px, 헤더 있는 카드는 17px) | **CardHeader 없이 CardBody 만 쓰면 위 여백이 없다** |
| V3 | 태그(Combobox 다중) 칸이 위 Select 와 다르다 — 글자 시작 5px 대 13px, 꺾쇠 text-primary·불투명 대 text-secondary·50% | **Select 계열 트리거의 모양이 통일돼 있지 않다** |

기록할 것: AI 가 `.sr-only` · `.tabular` 를 앱 CSS 에 다시 정의했다 — 이미 제공되는지 알려 주는 안내가 없다.
측정 실수 기록: 처음에 라디오 3개를 "이름 없는 버튼"으로 셌다 — `<Label htmlFor>` 연결을 보지 않은 내 검사의 잘못이다.
접근성 트리로 재니 "전체 공개 · 회원 공개 · 비공개" 로 정상이었다.

## AI 가 직접 만들어야 했던 것 — 준비도 신호

- **앱 셸**(사이드 내비게이션 · 페이지 머리) — 디자인 시스템에 없다. 네 제품 모든 화면에 필요하다
- **검색 입력의 아이콘** — V1
- **대표 이미지 업로드 영역**(점선 상자) — 파일 업로드 컴포넌트가 없다
- 예약 "발행일" 을 날짜로만 받았다 — 날짜+시간 선택이 없다
